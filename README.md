# Infinite Temple

In the cold void between dying stars, there exist structures that predate humanity's first breath—temples raised by intelligences so alien that to comprehend their purpose would shatter the mortal mind. You pilot a lone vessel through these cyclopean corridors, where geometry bends to forgotten magics and the silence is broken only by the hum of your engines and the stirring of things best left undisturbed. Each temple is generated anew from eldritch seeds, its halls populated by the remnants of civilizations that learned too late what slumbered in the spaces between worlds. There is no escape, only deeper descent into architectures of madness.

## Download

Pre-built executables are available from the [Releases](https://github.com/lkacenja/infinite_temple/releases) page.

## Running from Source

```bash
make setup   # Install dependencies
make run     # Launch the game
```
